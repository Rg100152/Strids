## 📖 Project Overview

**Strides Athletics** is a fully responsive, modern, and aesthetically polished **Login Page** developed as my **BCA (Bachelor of Computer Applications) Final Year Project**. 

This project demonstrates core front-end web development skills, focusing on:
- **High-fidelity UI/UX:** Replicating professional design layouts using pure CSS.
- **Robust Client-Side Logic:** Implementing real-time form validation and interactive alerts using Vanilla JavaScript.
- **Responsive Architecture:** Ensuring flawless display across desktop, tablet, and mobile devices.

The design philosophy reflects a **dynamic, athletic, and professional aesthetic**, combining vibrant crimson gradients with clean, white form interfaces for a standout user experience.

---

## 🚀 Key Features

✅ **Split-Screen Modern Layout:** A perfectly balanced horizontal card design with a vibrant gradient panel on the left and a clean form panel on the right.  
✅ **Pure CSS Abstract Art:** The left panel features hand-coded CSS gradients, glowing circles, and stylized mountain silhouettes, perfectly mimicking the reference design without using any external images.  
✅ **Smart Form Validation:** A built-in JavaScript function intercepts the "Login" submission, validates that both "User Name" and "Password" fields are filled, and triggers a custom success notification.  
✅ **Interactive Navigation:** A top-right mini-navbar with an active "Home" state and hover effects for seamless UI flow.  
✅ **Fully Responsive Layout:** Uses Flexbox to gracefully collapse into a single-column layout on tablets and smartphones, ensuring accessibility everywhere.  
✅ **Zero External Dependencies:** The entire application (HTML, CSS, and JS) is contained within a single file, making it exceptionally portable and easy to run.  
✅ **Professional Input Styling:** Custom placeholder fonts (cursive script) and thin crimson borders on inputs, matching the exact visual cues of the original design.
